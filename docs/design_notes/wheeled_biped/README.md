# Wheeled-Biped Research and Design Notes

This folder preserves the research and implementation plans that preceded the wheeled-biped controller.
These are working notes, not formal descriptions of the current implementation.
Their checklists, proposed features and verification statements describe the initial design stage and may be superseded.

- [Model and MPC survey](wheeled_biped_wb_id_mpc_survey.md): model selection, literature references and proposed formulation.
- [First implementation step](wheeled_biped_first_step.md): original porting checklist and acceptance-test plan.

For implemented equations and parameters, read [Wheeled-Biped WB-ID MPC](../../wheeled_biped_whole_body_inverse_dynamics_mpc.md).
For build/test commands, measurements, open issues and resuming milestones, read the [handoff](../../wheeled_biped_handoff.md).
