# Wheeled-Biped Research and Design Notes

- [First implementation step](wheeled_biped_first_step.md): original porting checklist and acceptance-test plan.
- [Real hardware validation handoff](upkie_hardware_validation_handoff.md): missing hardware/safety integration, transition hardening and staged physical acceptance gates.
